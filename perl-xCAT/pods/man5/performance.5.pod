=head1 NAME

B<performance> - a table in the xCAT database.

=head1 SYNOPSIS

B<performance Attributes:>  I<timestamp>, I<node>, I<attrname>, I<attrvalue>, I<comments>, I<disable>

=head1 DESCRIPTION

Describes the system performance every interval unit of time.

=head1 performance Attributes:

=over 10


=item B<timestamp>

The time at which the metric was captured.

=item B<node>

The node name.

=item B<attrname>

The metric name.

=item B<attrvalue>

The metric value.

=item B<comments>

Any user-provided notes.

=item B<disable>

Set to 'yes' or '1' to comment out this row.

=back
