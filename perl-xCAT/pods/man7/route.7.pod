=head1 NAME

B<route> - a logical object definition in the xCAT database.

=head1 SYNOPSIS

B<route Attributes:>  I<gateway>, I<ifname>, I<mask>, I<net>, I<routename>, I<usercomment>

=head1 DESCRIPTION

Logical objects of this type are stored in the xCAT database in one or more tables.  Use the following commands
to manipulate the objects: B<mkdef>, B<chdef>, B<lsdef>, and B<rmdef>.  These commands will take care of
knowing which tables the object attributes should be stored in.  The attribute list below shows, in
parentheses, what tables each attribute is stored in.

=head1 route Attributes:

=over 6


=item B<gateway> (routes.gateway)

The gateway that routes the ip traffic from the mn to the nodes. It is usually a service node.

=item B<ifname> (routes.ifname)

The interface name that facing the gateway. It is optional for IPv4 routes, but it is required for IPv6 routes.

=item B<mask> (routes.mask)

The network mask.

=item B<net> (routes.net)

The network address.

=item B<routename> (routes.routename)

Name used to identify this route.

=item B<usercomment> (routes.comments)

Any user-written notes.

=back
