=head1 NAME

B<pdu> - a table in the xCAT database.

=head1 SYNOPSIS

B<pdu Attributes:>  I<node>, I<nodetype>, I<pdutype>, I<outlet>, I<username>, I<password>, I<snmpversion>, I<community>, I<snmpuser>, I<authtype>, I<authkey>, I<privtype>, I<privkey>, I<seclevel>, I<comments>, I<disable>

=head1 DESCRIPTION

Parameters to use when interrogating pdus

=head1 pdu Attributes:

=over 10


=item B<node>

The hostname/address of the pdu to which the settings apply

=item B<nodetype>

The node type should be pdu 

=item B<pdutype>

The type of pdu: irpdu (infrastructure PDU, SNMP), crpdu (collaborative PDU, ssh) or genpdu (generic SNMP PDU, PDU2-MIB)

=item B<outlet>

The pdu outlet count

=item B<username>

The remote login user name

=item B<password>

The remote login password

=item B<snmpversion>

The version to use to communicate with switch.  SNMPv1 is assumed by default.

=item B<community>

The community string to use for SNMPv1/v2

=item B<snmpuser>

The username to use for SNMPv3 communication, ignored for SNMPv1

=item B<authtype>

The authentication protocol(MD5|SHA) to use for SNMPv3.

=item B<authkey>

The authentication passphrase for SNMPv3 

=item B<privtype>

The privacy protocol(AES|DES) to use for SNMPv3.

=item B<privkey>

The privacy passphrase to use for SNMPv3.

=item B<seclevel>

The Security Level(noAuthNoPriv|authNoPriv|authPriv) to use for SNMPv3.

=item B<comments>

Any user-written notes.

=item B<disable>

Set to 'yes' or '1' to comment out this row.

=back
