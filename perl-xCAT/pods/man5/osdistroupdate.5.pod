=head1 NAME

B<osdistroupdate> - a table in the xCAT database.

=head1 SYNOPSIS

B<osdistroupdate Attributes:>  I<osupdatename>, I<osdistroname>, I<dirpath>, I<downloadtime>, I<comments>, I<disable>

=head1 DESCRIPTION

Information about the OS distro updates in the xCAT cluster

=head1 osdistroupdate Attributes:

=over 10


=item B<osupdatename>

Name of OS update. (e.g. rhn-update1)

=item B<osdistroname>

The OS distro name to update. (e.g. rhels)

=item B<dirpath>

Path to where OS distro update is stored. (e.g. /install/osdistroupdates/rhels6.2-x86_64-20120716-update) 

=item B<downloadtime>

The timestamp when OS distro update was downloaded..

=item B<comments>

Any user-written notes.

=item B<disable>

Set to 'yes' or '1' to comment out this row.

=back
