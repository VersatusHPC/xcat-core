=head1 NAME

B<kitrepo> - a logical object definition in the xCAT database.

=head1 SYNOPSIS

B<kitrepo Attributes:>  I<compat_osbasenames>, I<kitname>, I<kitrepodir>, I<kitreponame>, I<osarch>, I<osbasename>, I<osmajorversion>, I<osminorversion>

=head1 DESCRIPTION

Logical objects of this type are stored in the xCAT database in one or more tables.  Use the following commands
to manipulate the objects: B<mkdef>, B<chdef>, B<lsdef>, and B<rmdef>.  These commands will take care of
knowing which tables the object attributes should be stored in.  The attribute list below shows, in
parentheses, what tables each attribute is stored in.

=head1 kitrepo Attributes:

=over 6


=item B<compat_osbasenames> (kitrepo.compat_osbasenames)

List of compatible OS base names.

=item B<kitname> (kitrepo.kitname)

The Kit name which this Kit Package Repository belongs to.

=item B<kitrepodir> (kitrepo.kitrepodir)

The path to Kit Repository directory on the Mgt Node.

=item B<kitreponame> (kitrepo.kitreponame)

The unique generated kit repo package name, when kit is added to the cluster.

=item B<osarch> (kitrepo.osarch)

The OS distro arch which this repository is based on.

=item B<osbasename> (kitrepo.osbasename)

The OS distro name which this repository is based on.

=item B<osmajorversion> (kitrepo.osmajorversion)

The OS distro major version which this repository is based on.

=item B<osminorversion> (kitrepo.osminorversion)

The OS distro minor version which this repository is based on. If this attribute is not set, it means that this repo applies to all minor versions.

=back
