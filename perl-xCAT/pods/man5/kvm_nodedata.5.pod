=head1 NAME

B<kvm_nodedata> - a table in the xCAT database.

=head1 SYNOPSIS

B<kvm_nodedata Attributes:>  I<node>, I<xml>, I<comments>, I<disable>

=head1 DESCRIPTION

Persistent store for KVM plugin, not intended for manual modification.

=head1 kvm_nodedata Attributes:

=over 10


=item B<node>

The node corresponding to the virtual machine

=item B<xml>

The XML description generated by xCAT, fleshed out by libvirt, and stored for reuse

=item B<comments>

Any user-written notes.

=item B<disable>

Set to 'yes' or '1' to comment out this row.

=back
