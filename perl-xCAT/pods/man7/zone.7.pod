=head1 NAME

B<zone> - a logical object definition in the xCAT database.

=head1 SYNOPSIS

B<zone Attributes:>  I<defaultzone>, I<sshbetweennodes>, I<sshkeydir>, I<usercomment>, I<zonename>

=head1 DESCRIPTION

Logical objects of this type are stored in the xCAT database in one or more tables.  Use the following commands
to manipulate the objects: B<mkdef>, B<chdef>, B<lsdef>, and B<rmdef>.  These commands will take care of
knowing which tables the object attributes should be stored in.  The attribute list below shows, in
parentheses, what tables each attribute is stored in.

=head1 zone Attributes:

=over 6


=item B<defaultzone> (zone.defaultzone)

If nodes are not assigned to any other zone, they will default to this zone. If value is set to yes or 1.

=item B<sshbetweennodes> (zone.sshbetweennodes)

Indicates whether passwordless ssh will be setup between the nodes of this zone. Values are yes/1 or no/0. Default is yes. 

=item B<sshkeydir> (zone.sshkeydir)

Directory containing the shared root ssh RSA keys.

=item B<usercomment> (zone.comments)

Any user-provided notes.

=item B<zonename> (zone.zonename)

The name of the zone.

=back
