=head1 NAME

B<rack> - a logical object definition in the xCAT database.

=head1 SYNOPSIS

B<rack Attributes:>  I<displayname>, I<height>, I<num>, I<rackname>, I<room>, I<usercomment>

=head1 DESCRIPTION

Logical objects of this type are stored in the xCAT database in one or more tables.  Use the following commands
to manipulate the objects: B<mkdef>, B<chdef>, B<lsdef>, and B<rmdef>.  These commands will take care of
knowing which tables the object attributes should be stored in.  The attribute list below shows, in
parentheses, what tables each attribute is stored in.

=head1 rack Attributes:

=over 6


=item B<displayname> (rack.displayname)

Alternative name for rack. Only used by PCM.

=item B<height> (rack.height)

Number of units which can be stored in the rack.

=item B<num> (rack.num)

The rack number.

=item B<rackname> (rack.rackname)

The rack name.

=item B<room> (rack.room)

The room in which the rack is located.

=item B<usercomment> (rack.comments)

Any user-written notes.

=back
