=head1 NAME

B<auditlog> - a logical object definition in the xCAT database.

=head1 SYNOPSIS

B<auditlog Attributes:>  I<args>, I<audittime>, I<clientname>, I<clienttype>, I<command>, I<comments>, I<disable>, I<noderange>, I<recid>, I<status>, I<userid>

=head1 DESCRIPTION

Logical objects of this type are stored in the xCAT database in one or more tables.  Use the following commands
to manipulate the objects: B<mkdef>, B<chdef>, B<lsdef>, and B<rmdef>.  These commands will take care of
knowing which tables the object attributes should be stored in.  The attribute list below shows, in
parentheses, what tables each attribute is stored in.

=head1 auditlog Attributes:

=over 6


=item B<args> (auditlog.args)

The command argument list.

=item B<audittime> (auditlog.audittime)

The timestamp for the audit entry.

=item B<clientname> (auditlog.clientname)

The client machine, where the command originated.

=item B<clienttype> (auditlog.clienttype)

Type of command: cli, java, webui, other.

=item B<command> (auditlog.command)

Command executed. See auditskipcmds site table attribute to control which commands get logged.

=item B<comments> (auditlog.comments)

Any user-provided notes.

=item B<disable> (auditlog.disable)

Do not use.  tabprune will not work if set to yes or 1

=item B<noderange> (auditlog.noderange)

The noderange on which the command was run.

=item B<recid> (auditlog.recid)

The record id.

=item B<status> (auditlog.status)

Allowed or Denied.

=item B<userid> (auditlog.userid)

The user running the command.

=back
