=head1 NAME

B<prodkey> - a table in the xCAT database.

=head1 SYNOPSIS

B<prodkey Attributes:>  I<node>, I<product>, I<key>, I<comments>, I<disable>

=head1 DESCRIPTION

Specify product keys for products that require them

=head1 prodkey Attributes:

=over 10


=item B<node>

The node name or group name.

=item B<product>

A string to identify the product (for OSes, the osname would be used, i.e. wink28

=item B<key>

The product key relevant to the aforementioned node/group and product combination

=item B<comments>

Any user-written notes.

=item B<disable>

Set to 'yes' or '1' to comment out this row.

=back
