=head1 NAME

B<firmware> - a table in the xCAT database.

=head1 SYNOPSIS

B<firmware Attributes:>  I<node>, I<cfgfile>, I<comments>, I<disable>

=head1 DESCRIPTION

Maps node to firmware values to be used for setup at node discovery or later

=head1 firmware Attributes:

=over 10


=item B<node>

The node id.

=item B<cfgfile>

The file to use.

=item B<comments>

Any user-written notes.

=item B<disable>

Set to 'yes' or '1' to comment out this row.

=back
