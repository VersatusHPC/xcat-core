=head1 NAME

B<osdistroupdate> - a logical object definition in the xCAT database.

=head1 SYNOPSIS

B<osdistroupdate Attributes:>  I<dirpath>, I<downloadtime>, I<osdistroname>, I<osupdatename>, I<usercomment>

=head1 DESCRIPTION

Logical objects of this type are stored in the xCAT database in one or more tables.  Use the following commands
to manipulate the objects: B<mkdef>, B<chdef>, B<lsdef>, and B<rmdef>.  These commands will take care of
knowing which tables the object attributes should be stored in.  The attribute list below shows, in
parentheses, what tables each attribute is stored in.

=head1 osdistroupdate Attributes:

=over 6


=item B<dirpath> (osdistroupdate.dirpath)

Path to where OS distro update is stored. (e.g. /install/osdistroupdates/rhels6.2-x86_64-20120716-update) 

=item B<downloadtime> (osdistroupdate.downloadtime)

The timestamp when OS distro update was downloaded..

=item B<osdistroname> (osdistroupdate.osdistroname)

The OS distro name to update. (e.g. rhels)

=item B<osupdatename> (osdistroupdate.osupdatename)

Name of OS update. (e.g. rhn-update1)

=item B<usercomment> (osdistroupdate.comments)

Any user-written notes.

=back
