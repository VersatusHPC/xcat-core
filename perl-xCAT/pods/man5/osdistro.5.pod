=head1 NAME

B<osdistro> - a table in the xCAT database.

=head1 SYNOPSIS

B<osdistro Attributes:>  I<osdistroname>, I<basename>, I<majorversion>, I<minorversion>, I<arch>, I<type>, I<dirpaths>, I<comments>, I<disable>

=head1 DESCRIPTION

Information about all the OS distros in the xCAT cluster

=head1 osdistro Attributes:

=over 10


=item B<osdistroname>

Unique name (e.g. rhels6.2-x86_64)

=item B<basename>

The OS base name (e.g. rhels)

=item B<majorversion>

The OS distro major version.(e.g. 6)

=item B<minorversion>

The OS distro minor version. (e.g. 2)

=item B<arch>

The OS distro arch (e.g. x86_64)

=item B<type>

Linux or AIX

=item B<dirpaths>

Directory paths where OS distro is store. There could be multiple paths if OS distro has more than one ISO image. (e.g. /install/rhels6.2/x86_64,...)

=item B<comments>

Any user-written notes.

=item B<disable>

Set to 'yes' or '1' to comment out this row.

=back
